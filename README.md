# ML Classification Lab

A reproducible machine-learning classification project using scikit-learn's built-in Breast Cancer Wisconsin dataset.

> **Important:** This is an educational ML project, not a medical device. It must not be used for diagnosis or clinical decisions.

## What this project demonstrates

- Data inspection and stratified train/test split
- Preprocessing inside a `Pipeline` to avoid data leakage
- Baseline and comparison models: Logistic Regression and Random Forest
- Cross-validation on the training set
- Evaluation with precision, recall, F1, ROC-AUC and a confusion matrix
- Reproducible results with fixed random seeds
- Unit tests for the data split and training workflow

## Dataset

The dataset is included with scikit-learn, so no manual download is required. It contains 569 samples and 30 numeric features. The target classes describe whether a sample is labelled benign or malignant in the source dataset.

## Setup

Python 3.10+ is recommended.

### Windows PowerShell

```powershell
py -m venv .venv
.venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, you can run the environment's Python directly:

```powershell
.venv\\Scripts\\python.exe -m pip install -r requirements.txt
```

## Run

From the project root:

```powershell
python -m src.train
```

The script prints cross-validation and test metrics, then writes results to `reports/`:
- `metrics.json`
- `model_comparison.csv`
- `confusion_matrix.png`
- `roc_curve.png`
- `permutation_importance.png`

The `reports/` folder is generated by the script and is excluded from Git by default. For a portfolio, you can choose to commit selected plots and metrics after running and checking them.

## Run tests

```powershell
python -m pytest
```
